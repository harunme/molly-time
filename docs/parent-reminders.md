# 家长主动视频提醒

在管理后台的「家庭设置 → 电视管理 → 家长视频提醒」上传两段 MP4：

1. 剩 1 集提醒，例如「茉莉，还剩一集哦」。
2. 休息提醒，例如「这一集看完啦，我们休息一下吧」。

视频使用现有的断点续传、容量检查和媒体处理流程。上传进度、暂停、续传和失败重试显示在对应提醒视频的选择框下方，无需前往资源库；两段视频都处理完成后才能发起提醒。提醒文件夹默认保持草稿，不进入电视片单，家长可在设置里预览。

在「概览 → 播放控制」选择在线的已配对电视，点击「发起提醒：只剩 1 集」。播放器每 2 秒读取提醒状态，暂停节目播放家长提醒，再从原位置继续。正在看的这一集就是最后一集；如果没有活跃播放会话，接下来启动的一集就是最后一集。结束后播放休息提醒视频，退出播放器。两段提醒视频不创建观看会话，不计入观看时长。

服务端按设备保存限制，禁止切到其他视频；最后一集完成后，禁止重新播放。提前退出可以继续同一集。重启电视或服务端不会清除限制。家长在概览中点击「恢复播放」解除限制，也可取消尚未完成的提醒。

设备列表显示在线状态及最近连接时间，在线设备优先。90 秒内有经过认证的心跳或播放上报算在线；列表每 5 秒刷新，发起时服务端再次检查。离线设备不能发起提醒，但已有的播放限制仍可解除。电视停在首页时也会每 30 秒检查连接，无需播放视频。

范围是选中的电视设备，该设备上的所有儿童档案共用同一次提醒。其他电视不受影响。这项功能停止播放器，不关闭电视电源。

旧服务器没有提醒接口时，播放器保持原有连播行为。部署需要同步更新 API、管理网页与 TV 网页；原生电视播放器也需要更新 APK。发布前仍需在实机验证遥控器退出、暂停恢复、断网重试和媒体播放。

验证：`apps/server/tests/test_reminders.py` 覆盖设备隔离、权限、私有媒体、单集限制和恢复播放；`apps/web/tests/reminders.spec.ts` 覆盖上传与主动提醒的完整浏览器流程。日常验证使用临时测试数据库，不启动 Docker 或 Android 模拟器。

## 与观看安排共存

开启新版[观看安排](watch-control.md)的电视使用统一的允许观看、加看和休息操作，原发起提醒和恢复播放不会绕过观看安排。已上传视频继续作为可选提示；没有视频也能生效。未开启观看管理的电视保持本页原有行为。
