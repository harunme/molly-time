# TV 界面与遥控器设计

日期：2026-10-12。已实现于 `apps/tv/web/`，管理后台的首页比例预览同步更新。

参考 [Norigin React demo](https://github.com/NoriginMedia/Norigin-Spatial-Navigation/tree/main/apps/react-demo)：借鉴侧栏、选中内容预览、水平内容行与分组焦点的结构。保留现有 Molly API 和 Bridge 1，不引入 demo 的 styled-components 或演示媒体数据。

## 视觉与布局

- 画布 `#1b172b`、侧栏 `#2d2244`、内容面 `#392851`；薰衣草紫强调 `#c4a7ff`，薄荷绿焦点 `#78ffd6`。缺失封面的稳定配色也使用紫色层次；实际视频封面保留自身色彩。
- 左侧固定首页、儿童选择和设置；当前观看儿童显示在侧栏底部。退出与连接地址放在设置弹层。
- 上方预览区固定，选中内容改变标题、封面、集数或时长与操作提示。系列、季和剧集逐层浏览，导航路径和返回入口保持可见。
- 首页栏目、季和剧集均为横向内容行。横向滚动不移动其他行，纵向换行只滚动下方列表，不移动预览区或整个页面。
- 使用系统中文字体和无衬线标题，不下载外部字体；字号和间距按屏幕宽高缩放。检查 960×540、1920×1080、3840×2160；尊重减少动画偏好。
- 没有封面时用资源名称和稳定配色生成文字封面，不伪造海报、推荐分类、评分或播放记录。只有临近视口的卡片请求图片；大预览请求 960px 封面。

焦点卡片在 200ms 内放大至 1.045 倍，封面采用 16px 基准圆角、薄荷绿描边与柔光；横向内容行在 220ms 内平滑将选中项带到前端。标题切换使用短淡入/上移，弹层淡入展开。减少动画偏好下取消这些位移动效。

快速方向键按当前行的确定顺序选卡片，滚动目标按未缩放的位置计算。新输入替换尚未完成的滚动；保存页面或播放返回位置前先结算动画，防止遗留动画覆盖恢复位置。

## 焦点与返回

`FocusContext` 分为屏幕、侧栏、内容、滚动列表、单行和弹层。内容行保存上次选中的子项；上下换行再返回时恢复它。首张卡片按左进入侧栏，侧栏按右回到上次内容卡片。

进入系列或季时保存当前卡片、纵向位置及各行横向位置；返回时恢复完整视图。原生播放退出后恢复剧集卡片；首页中的继续观看播放退出后重新读取已发布首页并恢复存在的卡片。内容被移除时回到有效入口。

儿童与设置使用方向键焦点边界，背景按钮暂时不可聚焦；返回关闭弹层并恢复打开它的菜单位置。选择儿童后读取该儿童首页。弹层内容较多时，焦点自动带动弹层自身滚动。
