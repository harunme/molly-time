# 家庭存储与流量用量

账号已有必填的 `users.family_id` 外键，一个账号归属一个家庭。此功能沿用现有归属与隔离，同一家庭全部账号、设备的用量合并统计。

## 页面与权限

- 家长后台 **家庭设置 → 家庭用量**：查看本家庭当前文件占用与指定月份流量。
- 超管后台 **运营设置 → 家庭用量**：按家庭、邮箱或账号 ID 搜索、分页查看所有家庭，导出指定月份的 CSV。
- 普通家庭账号不能查看其他家庭的报表或导出平台用量；设备令牌不能使用运营接口。

## 统计口径

所有原始数量使用整数 **字节**，CSV 不做 GB 舍入。流量月份固定为 `Asia/Shanghai` 自然月，与可修改的观看报表时区分开。查询范围是月初零点（包含）至下月月初零点（不包含）。

`storage.usedBytes` 为当前已入库文件占用，包含视频、字幕、封面、归档资源和被替换后仍保留的版本；同家庭、同后端、同路径只统计一次。服务器本地文件使用实际文件大小，旧文件未填写 `size_bytes` 也能统计；OSS 使用完成上传时服务端核验的大小。大小未知的 OSS 文件通过 `unknownSizeCount` 明确显示，不把它伪装成完整统计。

`pendingBytes` 是未入库上传的已知占用：本地临时文件实际大小，以及已完成 OSS 对象、正在处理或处理失败的大小。上传预留 `reservedBytes` 另列，不能作为实际消费计费。未完成的 OSS 分片、派生缓存、处理临时副本、数据库、共享客户端安装包不计入家庭文件占用；这些平台成本需要另外核算。

存储是**查询时的当前占用**，选择历史月份不会生成历史存储或 GB·月账单。此功能提供用量依据，不设置价格、自动扣款或存储时间积分。计费若按月平均占用，需要后续补充存储历史采样/变更台账与结算规则。

流量包括：

- `traffic.localBytes`：家庭媒体响应体成功交给 ASGI 发送接口的字节，包括 Range 视频、下载、家长提醒视频、字幕和实际返回的缩放封面。断开时只累计发送成功的块；HEAD、416、拒绝访问、302 跳转及播放解析不计。它不是客户端确认收讫或运营商网络账单；代理缓存/重传应在部署层核对。
- `traffic.ossBytes`：从 OSS 访问日志入账的公网 GetObject 实际返回字节（200/206），按请求发生时间汇总。解析地址、HEAD、上传、内网请求和 CDN 回源不计入；TV 缓存重播没有新的 OSS 请求，也不重复计入。
- `traffic.totalBytes`：以上两项之和。TV 本地缓存重复播放不发起媒体请求，因此不重复计网络流量。

`family_traffic_events` 为追加式台账，保留家庭、来源、字节数、请求时间和入账时间。历史 OSS 记录保留，用量报表仍可查询。

服务启动自动建表并记录 `family-usage-v1`。本地流量从启用后开始统计；原先未记录的流量不能追溯。OSS 同步需按下文启用；未启用时仅显示历史已入账数据，不能理解为完整 OSS 用量。

## API

- `GET /api/manage/usage?month=YYYY-MM`：当前会话所属家庭。
- `GET /api/manage/operations/usage?month=YYYY-MM&q=...&page=1&pageSize=20`：超管分页报表。
- `GET /api/manage/operations/usage/export?month=YYYY-MM&q=...`：导出所有匹配家庭，CSV 中存储列明确为当前占用。

默认月份为北京时间当前月。查询错误月份返回 422。历史月份的存储列仍为当前占用，流量列按所选月份取台账。

## OSS 公网下行自动统计

在媒体 Bucket 的阿里云控制台开启 **日志管理 → 日志转存**。建议目标为同地域、同账号的独立私有日志 Bucket，前缀设为 `molly-access/`，避免同 Bucket 日志循环。应用不会自动修改云端日志配置。

API 服务环境增加（重启生效）：

```dotenv
MOLLYTIME_OSS_LOG_BUCKET=your-private-log-bucket
MOLLYTIME_OSS_LOG_PREFIX=molly-access/
MOLLYTIME_OSS_LOG_SYNC_SECONDS=3600
MOLLYTIME_OSS_LOG_LOOKBACK_DAYS=7
```

同步使用运营设置中的媒体 Bucket、Endpoint 和 OSS 身份。为该身份额外授予目标日志 Bucket 的 `oss:ListObjects` 和指定日志前缀的 `oss:GetObject`；媒体 Bucket 原有权限不变。同地域阿里云服务器配置内网 Endpoint，可避免读取日志产生公网下行。

服务启动独立线程，每小时自动扫描最近七个 UTC 日期的标准日志名前缀（涵盖北京时间日期边界）。以对象名及 ETag 记录已处理日志，以源 Bucket＋Request ID 去重请求；晚到、重叠、重复扫描的日志不会重复入账。按北京时间请求发生月份记账，跨月晚到会补回原月份。日志逐块下载至临时文件后入账，网络读取不占用数据库事务；格式错误整份回滚，后续重试，页面显示失败状态。同步状态只表示扫描完成，不保证该时段日志已经全部投递。

需要停机后补查更早日志时，可临时增加回看天数（3–366），或在相同服务环境手动运行一次：

```bash
MOLLYTIME_OSS_LOG_LOOKBACK_DAYS=90 apps/server/.venv/bin/python -m mollytime_server.oss_usage
```

新签发的视频播放、兼容跳转和封面直连地址携带 `x-molly-usage` 家庭标记，使用服务端 HMAC 验证并绑定具体对象。共享文件按实际观看家庭入账，不按对象路径的原上传家庭计费。无标记的历史地址、无效标记、已不存在的家庭和平台文件仅列入运营页的“未归属家庭”，不会猜测归属；轮换 `MOLLYTIME_AUTH_SECRET` 后，旧标记也会进入未归属。签名 URL、IP、原始日志及对象路径不写入流量台账。

家庭页和运营页显示同步是否启用、最近成功时间及失败提示；CSV 保留每家庭 OSS 字节及入账时间。运营页额外显示所选月份日志公网下行总量和未归属字节，这个总量不受家庭搜索条件影响，也不包含迁移前仅保留在家庭台账中的历史数据。

**这是成本分析统计，不是阿里云计费账单。** 官方日志预计 48 小时内生成，部分中断请求不会记录，不能据此准确结算费用；开通前没有保存的日志也无法恢复。这里只统计常规 GetObject 成功响应的公网字节，不覆盖请求费、存储费、低频取回费、CDN 或传输加速等独立计费项。参见 [官方日志格式及限制](https://help.aliyun.com/zh/oss/user-guide/logging)。日志自身也占存储和请求资源，建议配置合理保留期（例如 30 天），先完成入账与验收后再清理。

验收时在真实 Bucket 播放一段视频，等待日志投递，核对请求 ID、SentBytes 和家庭月份；再次同步确认字节不增，重播确认 TV 缓存命中片段不产生新下载。未配置真实日志 Bucket 的本地测试只验证解析、去重与报表，不能证明云端已启用统计。
