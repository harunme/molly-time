# MollyTime 架构

日期：2026-10-12。状态：WebView 壳子、TV 网页、原生播放器和家长管理后台基础版已实现，TV 模拟器播放与暂停统计闭环已验证；华为 V65 尚未实测。

## 1. 目标与范围

采用 **Kotlin WebView 壳子 + TV 网页 + 原生 Media3 播放器 + 一个 FastAPI 后台**。业务页面通过网页部署更新，播放器与设备适配通过 APK 更新。先服务家中的华为智慧屏，再按需求扩展家庭与儿童管理。

不依赖 Jellyfin Server、SDK 或协议，不 fork 整套媒体中心作为产品基础。现有 `apps/tv/client/` 已直接使用 Media3 和 MollyTime `/api/*`。历史 Jellyfin 客户端只作参考；Gradle 已只包含 `:client`；历史代码与许可后续单独整理。

首版不建设微服务、第二套业务后台、通用浏览器、插件系统、转码平台、下载缓存或严格离线限时。

## 3. 职责与技术选择

| 部分 | 技术与职责 |
| --- | --- |
| `apps/tv/client/` | Kotlin：WebView、受限 Bridge、凭证保存与刷新、遥控器/返回键衔接、原生播放、诊断 |
| `apps/tv/web/` | React + TypeScript + Vite：登录/绑定、儿童选择、首页、系列、剧集；Norigin Spatial Navigation 管理焦点 |
| `apps/server/` | FastAPI + SQLAlchemy + SQLite：唯一业务与媒体 API，保存家庭、儿童、目录、授权、配置、进度与事件 |
| `apps/web/` | 已实现家长管理界面，使用同一后台；资源上传、首页编排、观看记录与设备管理见 [使用说明](../apps/web/README.md) |
| 本地媒体目录 | 视频、字幕、封面，直接播放，不默认转码 |

TV 网页通过受限 Bridge 调用原生 API 客户端访问后台；原生播放器直接读取后台授权后的媒体流。第一版网页不持有 refresh token，不重复实现认证流程。后台是权限、目录和进度的权威来源。

日常开发只启动 TV 网页 Vite 服务，在浏览器中调试；API 按需使用已有后台或本地 Python 服务，不启动 Docker 和 Android。发版前再用 Android 客户端验证 WebView、Bridge 与原生播放。家庭部署时网页与 API 使用同一 HTTPS 入口。FastAPI 可直接提供构建后的静态文件，避免新增常驻前端服务。SQLite 用于单主机家庭阶段，有并发写入或部署需求后再迁移 PostgreSQL。不另建 `services/business-api/`。

## 4. 网页与原生接口

Bridge 第一版只暴露以下有限能力：

- `getCapabilities`：Bridge 版本、壳子版本与可用能力。
- `pairingStart` / `pairingPoll` / `pairingCancel`：手机网页确认扫码绑定，原生保存配对秘密与设备凭证；网页仅接收公开短码、二维码和配对状态。电视通过 `pairingReset` 经确认后解除自身绑定并重新配对；家长也可在网页后台远程取消。
- `request`：仅允许白名单中的 MollyTime API 路径与方法，不接受任意主机、URL、请求头或文件路径。
- `playEpisode`：传入剧集 ID 与儿童上下文；原生向后台校验授权、读取续播与媒体信息后启动 PlaybackActivity。
- `playbackClosed`：播放返回事件，网页刷新进度并恢复原卡片焦点。

消息带请求 ID、统一成功/错误结果和超时。Bridge 独立版本化，网页启动先检查能力，不支持的新能力隐藏或提示更新 APK。仅固定可信来源可调用 Bridge，拦截外部导航与子框架调用；生产关闭 WebView 调试。家长配置首页只下发受校验的数据，不允许任意 HTML/JS。

方向键与确认键交给网页焦点系统；原生负责系统按键衔接。返回顺序为播放页、网页弹层、网页路由、首页退出。保留路由、列表位置和卡片 ID，避免播放返回后重新开始。首版使用原生播放控件，暂不做网页覆盖视频画面的双层合成。

## 5. 热更新分两步

### 第一步：部署网页即更新

壳子加载固定可信网页地址。入口禁止陈旧缓存，带内容哈希的资源长期缓存；发布保留旧资源，避免旧页面请求的文件被立即删除。网页保持与旧 Bridge/API 兼容。目前更新在下次启动时加载，播放中不刷新；返回首页自动检查更新尚未实现。

APK 内置简单故障页，提供重试与连接诊断；它不是离线业务页面。网页不可达时展示故障页，不承诺离线浏览。发布回退依靠服务端切回上一版入口。此阶段不建设下载器、签名包、灰度平台或 Service Worker 更新体系。

### 第二步：需要断网启动可靠性时增加网页包

APK 内置基础业务网页包；新包验证签名、文件完整性及最低 Bridge/壳子版本后，在非播放状态原子切换。保留上一份确认可启动的版本，以网页握手作为启动成功条件，失败回滚。通过 WebViewAssetLoader 的 HTTPS 风格来源加载本地资源；验证公钥在 APK 内，更新验证与执行由原生控制。

热更新覆盖 HTML/CSS/JS。Media3、原生库、权限、Bridge 新能力和 WebView 内核变化仍需 APK 或系统更新。

## 6. 媒体、授权与进度

- 首版使用本地 MP4 与 SRT/VTT。FFmpeg 用于输入检查、封面和必要的预处理，不默认转码。
- 视频按固定大小分块读取，正确处理 GET/HEAD、开放区间、后缀区间和 416，避免整部视频读入内存。多段 Range 明确拒绝或实现。
- 家庭权限覆盖目录、详情、视频、字幕、封面；儿童上下文由后台验证，不能只靠网页隐藏内容。设备绑定后使用可撤销的设备身份，不长期沿用管理员凭证。
- 原生 API 与播放器优先使用 Authorization 请求头，媒体请求头可通过 Media3 数据源配置。现有查询串 token 是原型行为，不是播放器能力限制。
- 续播进度以儿童、剧集为维度由后台保存；原生负责播放会话与事件，网页只显示结果。媒体位置与观看时长分开记录。
- 正式统计按会话与递增序号去重，暂停、缓冲和拖动不计时；网页更新不能重复计时。退出提交末次进度，失败事件持久化后补传。
- 上传与媒体处理先采用同一应用内的模块和可重跑命令。需要后台执行时使用持久化状态与独立执行进程，不先引入消息队列基础设施。

## 7. 实施顺序与验收

1. **V65 最小原型**：网页展示真实目录，Bridge 启动现有播放器；验证内核、图片滚动、方向键、返回焦点、视频、字幕、休眠恢复。模拟器只辅助调试。
2. **网页迁移与远程更新**：迁移登录、首页、系列与剧集；旧 APK 加载新网页，网络失败可重试，播放不中断；整理 Gradle 和历史文档。
3. **家庭使用闭环**：设备绑定、儿童选择、儿童独立续播、家长管理与上传。补齐媒体端点授权，再验收多家庭访问。
4. **家长管理与统计**：按 [管理后台设计](parent-admin-design.md) 完成资源发布、首页编排、原生播放计时和观看报表。
5. **按问题增强**：本地网页包、OSS/CDN、PostgreSQL 按需求分别实施。

已修正 Range 读取与边界、字幕家庭校验并接通儿童续播。设备身份、会话去重、观看统计和本地事件队列补传已实现；家长预览不计入统计。模拟器已验证网页登录、真实目录、Hello 视频、暂停不计时、原生播放返回焦点和 API 白名单，见 [本次验证](parent-admin-validation.md)。仍需实机验收生命周期、字幕切换与编码兼容；连续播放和离线网页包尚未实现。

目标电视：华为 V65（HD65THAA，2021 款），已记录 HarmonyOS 4.3.0.130。WebView 版本、APK 安装和播放兼容性仍须实机确认。

## 8. 开源参考与判断分工

- [mrowser](https://github.com/m-salehi-v/mrowser)：参考 WebView 与 Media3 衔接，不引入通用浏览器、流探测和虚拟鼠标。
- [Norigin Spatial Navigation](https://github.com/NoriginMedia/Norigin-Spatial-Navigation)：网页焦点导航候选，兼容性在 V65 验证。
- [Nodecast TV Android](https://github.com/jackduckworth2/nodecast_tv_android)：网页壳子流程参考，不迁入 IPTV 业务或 Flutter。

API 见 [server.md](server.md)。[历史验证记录](local-validation.md)不能视为新架构验收。复用代码时记录来源、版本与许可；TV 目录许可证边界在整理上游依赖时核对。

权限、更新验证、焦点算法、Range、计算和事件去重采用确定性代码。Codex 负责架构、实现和调试。Jev usage: Not used；本方案没有需要窄语义判断的产品功能，不引入 AI 依赖。

TV 绑定持久保存到后台取消：原生客户端使用私有存储，开发网页使用当前站点的本地存储。设备绑定不受账号会话三十天期限限制；短期访问令牌自动刷新，断网不清除绑定，TV 经确认可重新配对，家长管理网页可远程取消配对。
