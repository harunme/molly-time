# 家庭间内容分享

管理端资源库支持分享一个视频或整个合集。分享只包含创建时已发布且处理完成的内容、当前字幕和封面，保存固定版本快照。视频可以继承所属合集的封面。家长提醒素材和收到的内容不能再次分享。

分享链接和十二位口令七天内有效，可被多个家庭的管理员领取；链接采用 `/manage/#/share/十二位口令`，与手动输入口令使用同一份凭证，不生成单独 token。打开链接即可查看内容概览，点击“加入我的内容库”时以弹窗要求登录；合集登录成功后直接领取，单视频选择接收合集后领取。全程停留在公开分享页，成功后显示领取结果，不跳转管理后台。资源库工具栏的“领取分享”位于新建按钮前，点击后弹窗输入口令或链接。创建弹窗显示范围、容量、有效期及不可撤回提示；凭证仅创建时返回，数据库只保存哈希。不要在日志中记录分享凭证。

领取合集会创建新的草稿合集，领取单视频需要选择接收合集。家庭管理员自行发布收到的内容。接收后双方独立管理，不同步更新、不能撤回，不复制观看记录、首页配置、设备下载任务。相同家庭领取相同分享是幂等操作，删除后也不能通过同一分享再次领取。

## 文件与容量

创建与领取只保存数据库记录，OSS/本地文件保持同一份，媒体上传及播放接口不变。新的 `MediaFile` 属于接收家庭，复用来源的文件路径。文件替换使用新对象路径；分享快照和接收家庭仍引用原版本。字幕偏移、名称等配置分别保存在各家庭自己的记录中。

家庭容量包含当前文件、旧版本、回收站以及其未过期分享保留的文件，同一物理路径在家庭内只计算一次。收到的内容占用接收家庭配额，领取前校验新增占用；容量不足时整个操作失败。不同家庭可能引用同一对象，家庭容量之和不代表平台物理存储容量。

未过期快照保护文件，即使分享者彻底删除内容，其他家庭七天内仍可领取。接收成功后永久独立引用文件；来源删除不影响播放。回收站的释放空间会考虑有效分享与其他家庭引用。

worker 每五分钟释放过期快照引用，将文件加入持久化清理队列。只有不存在媒体关联、回收站保留、有效分享或上传任务引用时才删除文件。失败记录保留并重试。未运行 worker 时链接仍按时失效，但过期快照文件需等待 worker 启动才能回收。

已有 OSS 内容、分享快照或待清理对象时，禁止直接更换 Bucket/Endpoint。启动迁移移除单独的 token 字段，保留快照和领取记录，不移动文件；备份数据库时应连同新增分享表一起备份。

## 接口

创建与领取接口位于 `/api/manage/shares`，要求家庭管理员登录并通过现有 CSRF 校验。公开概览接口为 `POST /api/shares/preview`，只需口令；返回快照名称、简介、目录、数量、容量、时长和封面标识，不返回存储地址、文件路径或播放权限。公开封面接口 `POST /api/shares/images/{imageId}`（请求体提供 `code`） 仅允许读取该有效分享快照中的图片，过期即失效，不能用于访问视频或字幕。登录时附带当前家庭的领取状态，其他家庭和访客无法看到这些状态。所有响应不缓存，领取和查找有限流。

- `POST /prepare`：`resourceId`，返回可分享视频数量和大小，供创建前确认，不创建快照。
- `POST /`：`resourceId`，生成七天快照，返回链接、口令、截止时间及目录摘要。
- `POST /preview`：提供 `code`，返回名称、目录、容量和当前家庭领取状态；不下发媒体地址。
- `POST /accept`：提供 `code`，可选接收名称；单视频必须提供 `targetFolderId`。原子领取并返回 `resourceId`、`alreadyClaimed` 和 `deleted`。

文件保护与领取/删除通过现有数据目录的文件锁协调。API 和 worker 必须使用同一数据目录及已有的共享锁部署方式。
